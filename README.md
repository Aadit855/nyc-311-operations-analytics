# NYC 311 Operations Analytics

## Project Overview

This project analyzes NYC 311 service-request data to identify patterns in
request volume, complaint categories, resolution times, agencies, and locations.

The goal is to demonstrate how operational data can be transformed into clear
KPIs, dashboards, and practical business recommendations.

## Business Questions

1. Which complaint types generate the most service requests?
2. How does request volume change by month and weekday?
3. Which agencies and boroughs have the longest resolution times?
4. Where are unresolved requests concentrated?
5. What operational improvements could the data support?

## Tools

- SQL
- Microsoft Excel
- Tableau

## Data Source

[NYC 311 Service Requests from 2020 to Present](https://data.cityofnewyork.us/resource/erm2-nwe9)

## Planned Deliverables

- Data-quality assessment
